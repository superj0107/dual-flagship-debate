# 双旗舰通用对抗辩论协议（`dual-flagship-debate`）

由**当前对话主控**居中主持，调度两款同档顶配旗舰模型在完全隔离的只读会话中开展立论与无损交叉交锋，打破单模型顺从偏见（sycophancy），在真实约束下收敛出可落地结论与核心取舍。

## 一、角色分工与同档选模铁律

| 角色 | 运行方式 | 核心职责 |
|---|---|---|
| **主持人（当前主控）** | 当前会话主控（不移交主持权） | Step 0 核实基线、校验辩手组合与定模式，并行派发、**原文无损交叉转交**、独立事实核验与终局五栏裁决。 |
| **辩手 A** | 隔离只读子会话／子智能体（禁写死固定人设） | 由主控按 Step 0 选定模式动态分派辩论视角与审视重心。 |
| **辩手 B** | 独立隔离的另一只读子会话／子智能体（禁写死固定人设） | 由主控按 Step 0 选定模式动态分派对应视角与挑战重心。 |

**三级同档选模与反降级门禁**（参考配置与宿主范式见 `references/models-and-hosts.md`）：
1. **优先（双旗舰顶配）**：从宿主实时可用模型目录选取两款同梯队顶配旗舰（跨厂商异构最优，同厂商兄弟旗舰次之），双方均开最高推理档；若用户已在 `AGENTS.md`／`CLAUDE.md`／`GEMINI.md` 或当前对话指定合规同档组合，直接沿用。
2. **回退（单旗舰双隔离）**：仅暴露 1 款顶配旗舰时，自动改为同一顶配旗舰开两个完全隔离的只读会话（分派正交视角），并在裁决首行明示 `模式：同旗舰双隔离`。
3. **硬阻断**：宿主无法发起独立只读子会话、仅剩 `mini`／`flash`／`haiku`／`lite` 等轻量模型凑数、或无法开启对等高推理档时，**直接报错说明缺口并停止**，严禁静默降级或单上下文自我角色扮演。

**强制护栏**：① 两位辩手全程严格只读，严禁改文件、写库或外部写入；② 严禁跳过宿主实时模型目录照抄过期型号；③ Round 1 与 Round 2 均须同回合并行异步派发，等待唤醒，严禁轮询。

## 二、按议题自适应的 4 种博弈模式（Step 0 择一）

严禁写死固定行业人设。主控根据议题特征动态选择一种博弈模式写入派活单：
1. **双盲独立 → 交叉互搏**：适用开放复杂难题。双方互不可见各自先给出完整方案，再交叉拆台交锋。
2. **既定双案攻防（A vs B）**：适用已有明确双方案待二选一。两方各认领一案，做最强 Steelman 辩护并攻击对方漏洞。
3. **动态张力双轴**：适用开放权衡议题。主控提炼核心矛盾轴（如「彻底重构 vs 最小改动」「上限体验 vs 成本风控」），为两方分派互补重心。
4. **辩护 vs 事前验尸红队（Steelman vs Pre-Mortem Red Team）**：适用拟定方案待拍板。一方论证最强成立条件，另一方假定「方案半年至一年后彻底失败」执行 **Pre-Mortem ＋ 逆向检验**。

## 三、反谄媚与攻防质量硬规则（须写入双方 Prompt）

1. **孤立盲发破锚**：Round 1 双方完全隔离、不得猜测对方结论，强制基于客观事实独立推导。
2. **真理优先于和气（Anti-Sycophancy）**：禁止礼貌妥协与「综合都对」的稀泥共识；无新事实、反例或因果推导**严禁无故改口**；修正立场必须写明被哪条具体新证据推翻。
3. **先 Steelman 再打穿**：反驳前先用 1–2 句准确还原对方成立前提与最强论点，严禁稻草人攻击。
4. **原子化反驳结构**：每条反驳须锚定对手具体主张：`主张 → 缺陷类型 → 反证／替代路径`（缺陷限选：`事实／约束违背`、`隐含假设失效`、`边界／规模崩溃`、`激励或二阶反噬`、`逻辑跳跃`）。
5. **立场状态声明**：每轮开头显式声明：`CONVERGED`（已收敛）／`SHIFTED`（因新证据修正）／`MAINTAINING_DISSENT`（坚持分歧）。

## 四、标准四步主持协议

### Step 0｜拉齐客观事实基线 ＋ 选定模式与辩手
主控先确认辩手组合满足同档铁律（用户规则偏好 → 宿主实时目录 → 可选对照 `references/models-and-hosts.md`），再只读核查当前议题真实约束整理【客观事实基线】，**明确区分「已核实事实」与「待证假设」**，并写清核心决策问题与选定博弈模式（4 选 1）。

### Step 1｜Round 1：并行盲发立论 ＋ 互抛 3 个致命质询
同回合并行发起两个隔离只读子会话（`辩手 A`、`辩手 B`），要求限 `≤ 1,200` 字输出固定结构：① **立场状态**与对客观基线的校准补充；② **核心立场与推演**；③ **向对手抛出的 3 个致命质询**（直击最承重的未证假设或隐含代价）。若双方均 `CONVERGED` 且无实质分歧，可早停直接进入 Step 3。

### Step 2｜Round 2：双态无损交叉转交 ＋ 原子化反驳与找枢纽
收齐并读全双方 R1 原文后（截断须先补读完整内容），同回合并行启动 Round 2（限 `≤ 1,000` 字、纯只读），遵守 **R2 双态契约**：
- **有状态宿主**（支持原线程／会话续发）：直接将**未经主控总结洗稿的对方 R1 完整原文**发回各自 R1 原会话；
- **无状态宿主**（子会话一次性、无续发原语）：新开两个独立只读子会话，显式注入 `[Step 0 客观基线 + 本方 R1 完整原文 + 对手 R1 未洗稿原文]`，严禁主控单上下文精分。
固定输出 4 项：① **新立场状态与认账项**；② **逐条正面回应 3 个质询**（原子化结构，盲区必须认账）；③ **承重枢纽假设（Double Crux）与推翻条件**（1–2 个核心未证假设及止损线）；④ **收敛后的最终建议**。默认 **2 轮封顶**，复读即截断进入 Step 3。

### Step 3｜主控独立事实核验 ＋ 终局五栏裁决
1. **强制事实纠偏闸门**：辩手新引用的任何代码路径、配置、系统行为、数据或外部规则，主控能核实必须亲自只读验证；误报直接纠偏并标注实测依据，无法核实的标为「未核实前提」。
2. **终局五栏交付**（单旗舰回退时首行标 `模式：同旗舰双隔离`）：**① 裁决结论**（一句话建议＋辩手型号与会话引用）；**② 互辩撞出的关键修正与淘汰项**；**③ 幸存的收敛方案与护栏**；**④ 关键承重假设（Double Crux）与最小验证法**；**⑤ 仍未弥合的真正分歧**（各自最硬论据、代价与主控倾向，交用户拍板）。
